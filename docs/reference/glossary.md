# Glossary

| Term | Definition |
| --- | --- |
| **Air-gapped** | A cluster with no internet access |
| **Bundle** | The archive the installer deploys from: manifests, Pulumi deployments, charts and CRDs |
| **CRD** | Custom Resource Definition - a Kubernetes API extension |
| **EPP** | Endpoint Picker - selects which replica serves a request |
| **GAIE** | Gateway API Inference Extension |
| **Gateway API** | Kubernetes standard for ingress and routing |
| **InferencePool** | A set of interchangeable replicas of one model |
| **Istio** | Service mesh providing the gateway data plane |
| **KV cache** | Cached attention state per request; a major VRAM consumer |
| **llm-d** | Framework orchestrating multiple coordinated inference instances |
| **MCP** | Model Context Protocol - a standard for tool/data integrations |
| **ModelService** | Deployable unit for a single model |
| **Nodegroup** | A labelled set of nodes used for workload placement |
| **OCI** | Open Container Initiative - image and artifact format |
| **ORAS** | OCI Registry As Storage - stores model weights as OCI artifacts |
| **Provisioning machine** | The host that runs the installer |
| **PVC** | PersistentVolumeClaim |
| **Stack** | A Pulumi deployment unit with its own configuration |
| **StorageClass** | Kubernetes storage provisioner definition |
| **vLLM** | The inference engine executing models on GPUs |
| **VRAM** | GPU memory |
