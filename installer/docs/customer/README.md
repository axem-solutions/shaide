# Shaide AI Platform Customer Documentation

This documentation is for customers preparing, installing, validating, and operating the Shaide AI Platform on managed Kubernetes within their own infrastructure.

Use this section when running a self-serve installation, verifying that the deployment is healthy, onboarding models, or troubleshooting installation-time issues.


## Installation Flow

1. Prepare the infrastructure and required access.
2. Run the Shaide installer.
3. Verify that the deployment is healthy.
